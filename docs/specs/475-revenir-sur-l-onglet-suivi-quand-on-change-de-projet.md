# 475 · Revenir sur l'onglet « Suivi » quand on change de projet

> Demande [#475](https://github.com/phoibe/factory/issues/475) · 2026-11-18

**En une phrase** : quand vous changez de projet dans le tableau de suivi, il s'ouvre toujours sur l'onglet « Suivi » du nouveau projet.

### Ce que j'ai décidé pour vous
- Ça vaut quelle que soit la façon de changer de projet (liste des projets sur ordinateur ou sur téléphone).
- Si vous recliquez sur le projet déjà ouvert, rien ne change : vous restez sur l'onglet où vous étiez.
- Quand le tableau se met à jour tout seul (réglages du projet modifiés, nouvelle version du tableau…) sans que vous ayez changé de projet, vous restez aussi sur votre onglet.

### Ce qui change
Aujourd'hui, si vous êtes sur « Agent » ou « Paramètres » et que vous passez à un autre projet, vous restez sur cet onglet. Désormais, le changement de projet vous ramène sur « Suivi ».

### Comment vérifier
1. Ouvrez un projet, allez sur l'onglet « Paramètres », puis choisissez un autre projet : l'onglet « Suivi » du nouveau projet s'affiche.
2. Même chose depuis l'onglet « Agent ».
3. Sur « Paramètres », recliquez sur le projet déjà ouvert : vous restez sur « Paramètres ».

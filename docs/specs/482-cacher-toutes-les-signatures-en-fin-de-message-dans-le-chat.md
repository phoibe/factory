# 482 · Cacher toutes les signatures en fin de message dans le chat

> Demande [#482](https://github.com/phoibe/factory/issues/482) · 2026-11-18

**En une phrase** : le chat de l'onglet « Agent » cache toutes les signatures de fin de message, en français comme en anglais, même quand plusieurs se suivent.

### Ce que j'ai décidé pour vous
- Sont cachées les signatures « Généré par Claude Code… », « Generated by Claude Code… » et « Message automatique de la software factory », avec le trait de séparation qui les précède.
- Quand plusieurs signatures se suivent en fin de message, elles disparaissent toutes.
- Seule la fin du message est concernée : une phrase identique au milieu d'un message reste affichée.

### Ce qui change
- Dans le chat, plus aucune ligne de signature ni aucun trait de séparation en bas des messages de l'agent.

### Comment vérifier
- Ouvrez l'onglet « Agent » et la conversation #481 : son dernier message se termine sans « Généré par… » ni « Generated by… ».
- Les autres messages de l'agent s'affichent comme avant, sans signature.

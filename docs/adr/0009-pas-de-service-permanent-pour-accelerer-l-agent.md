# Pas de service permanent pour accélérer l'agent de discussion

Chaque message de l'onglet « Agent » réveille un agent sur une machine neuve, ce qui impose un temps de démarrage.
Le rendre instantané demanderait un agent qui tourne en permanence, donc un service en plus, probablement payant :
le propriétaire l'a refusé. On raccourcit seulement ce qui dépend de nous (consignes, lectures) et on rend l'attente
lisible (temps écoulé, délai habituel). Décidé par le propriétaire dans la demande #460.

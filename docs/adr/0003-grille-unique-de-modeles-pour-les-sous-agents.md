# Une seule grille de modèles pour les sous-agents, l'agent principal reste sur la routine

Décidé avec le propriétaire (#309) : chaque sous-agent reçoit le modèle et l'effort de sa tâche selon une grille unique, écrite dans les consignes de la factory et la même pour tous les projets (pas de réglage par projet dans le panneau). L'agent principal d'un lancement garde le modèle de la routine (Opus) ; une 2ᵉ routine sur Sonnet pour les petites étapes ne se fera que si les économies ne suffisent pas.

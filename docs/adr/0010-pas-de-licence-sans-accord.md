# Pas de licence ajoutée sans l'accord du propriétaire

Choisir une licence (ce que les autres ont le droit de faire du code) est un choix juridique qui revient au
propriétaire. L'agent n'ajoute donc jamais de licence de lui-même à un projet, ni fichier ni mention dans la
présentation ; il la mentionne seulement si le projet en a déjà une. Décidé par le propriétaire dans la demande #466.

# Pas de skill pour rendre les agents moins bavards

Une skill de style télégraphique a été envisagée pour réduire la consommation (#628) et écartée : l'essentiel des tokens part dans la lecture, pas dans l'écriture (sur la préparation d'un round de questions, environ 3,7 millions de tokens lus pour 33 000 écrits), le gain serait donc minime. Et aucun message adressé au propriétaire ne doit devenir plus sec. À ne pas reproposer tant que la page « Consommation » ne montre pas que l'écriture pèse.

# Pas de bouton de cadrage dans le menu « Plus »

Décidé par le propriétaire (#354, demandé dans #335) : le bouton « Cadrer le projet » / « Revoir le cadrage » est retiré du menu « Plus » de chaque projet, et ne doit pas revenir. Le cadrage d'un nouveau projet s'ouvre tout seul à l'installation ; pour faire évoluer la fiche produit d'un projet déjà cadré, on passe par une demande de fonctionnalité ou par le chat.

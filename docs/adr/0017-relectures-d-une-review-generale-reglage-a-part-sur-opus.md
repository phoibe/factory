# Les relectures d'une review générale ont leur propre réglage, sur Opus au départ

Décidé avec le propriétaire (#570), en complément des rôles de modèle (0012) : les relectures partie par partie d'une review générale reçoivent un cinquième réglage dans les réglages généraux, au lieu de dépendre du réglage « Écriture du code ». Deux propositions ont été refusées : les faire suivre simplement le réglage « Revue », sans nouveau réglage, parce que le propriétaire veut choisir lui-même le moteur de ces relectures ; et mettre Fable au départ, parce que pour le moment il veut que la relecture partie par partie soit sur Opus. Le réglage ne porte que sur ces relectures (la synthèse et la relecture des corrections restent au rôle « Revue ») et se choisit une fois pour tous les projets dans les réglages généraux, pas à chaque lancement d'une review.

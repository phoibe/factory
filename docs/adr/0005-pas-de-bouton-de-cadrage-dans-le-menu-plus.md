# Pas de bouton de cadrage dans le menu « Plus »

Décidé par le propriétaire (#354) : le menu « Plus » de chaque projet n'a plus de bouton « Cadrer le projet » ni « Revoir le cadrage ». Le cadrage d'un nouveau projet s'ouvre tout seul à l'installation ; pour faire évoluer la fiche produit d'un projet déjà cadré, on passe par une demande de fonctionnalité ou par le chat. Ne pas reproposer ce bouton.

# Pas de licence ajoutée par l'agent

Décidé par le propriétaire (#466) : le choix d'une licence (ce que les autres ont le droit de faire du code) est juridique et lui revient. L'agent n'ajoute jamais de licence de lui-même à un projet, même si GitHub le recommande ; il se contente de l'indiquer dans la présentation du projet quand le projet en a déjà une.

# Pas de compte à rebours sur « go », « Ok » et « Jeter »

Décidé par le propriétaire (#450, demandé dans #448) : un toucher sur « go », « Ok » ou « Jeter » agit tout de suite. Les comptes à rebours de 5 secondes avec « Annuler » (ajoutés dans #123 et #402 pour rattraper un mauvais toucher) sont retirés et ne doivent pas être reproposés. Une idée jetée par erreur reste lisible et peut être rouverte sur GitHub.

# Pas de compte à rebours sur les boutons du tableau

Décidé par le propriétaire (#450, demandé dans #448) : un toucher sur « go », « Ok » ou « Jeter » agit tout de suite, sans compte à rebours ni bouton « Annuler ». Les 5 secondes pour rattraper un mauvais toucher (ajoutées pour « go » puis pour « Jeter » dans #402) sont retirées : « un go est un go immédiat ». Ne pas reproposer de délai d'annulation ni de fenêtre de confirmation sur ces boutons.

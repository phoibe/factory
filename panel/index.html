Connecte le panneau à GitHub

Le panneau a besoin d'un jeton GitHub pour lire tes projets et enregistrer tes règles. Il reste dans ce navigateur, nulle part ailleurs.

  1. Ouvre la création de jeton.
  2. Nom : « factory panneau ». Expiration : 1 an. Repository access : All repositories.
  3. Dans la boîte Repositories (pas « Account ») : + Add permissions, coche Contents, Issues et Pull requests, puis mets Contents et Issues sur « Read and write » (Pull requests reste en « Read-only »).
  4. Génère le jeton, copie-le et colle-le ici.

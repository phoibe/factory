Connectez le panneau à GitHub

Le panneau a besoin d'un jeton GitHub pour lire vos projets et enregistrer vos règles. Il reste dans ce navigateur, nulle part ailleurs.

Déjà connecté sur votre ordinateur ? Là-bas, cliquez sur Sur mon téléphone et scannez le code avec ce téléphone : rien à recopier.

  1. Ouvrez la page de création de jeton sur GitHub (elle s'ouvre dans un nouvel onglet).
  2. Dans « Token name », écrivez « factory panneau ». Dans « Expiration », choisissez 1 an.
  3. Dans « Repository access », choisissez « All repositories ».
  4. Plus bas, dans la boîte « Repositories » (pas « Account »), cliquez sur « Add permissions ».
  5. Cochez « Contents », « Issues » et « Pull requests ».
  6. Mettez « Contents » et « Issues » sur « Read and write ». « Pull requests » reste sur « Read-only ».
  7. Cliquez sur « Generate token », copiez le jeton et collez-le ici.

Aucun projet pour l'instant

Un projet de la factory est un dépôt qui contient factory.config.json. Créez-en un à partir du modèle, puis revenez ici.

Télécharger les outils Mac

Décompressez le fichier, puis double-cliquez sur « Nouveau projet » ou « Adopter un projet » : une fenêtre vous pose les questions et fait tout le reste.
